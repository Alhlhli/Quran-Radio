## 🕌 نبذة عن المشروع

**راديو القرآن الكريم** هو تطبيق ويب خفيف الوزن مبني بـ HTML خالص، يتيح للمستخدم الاستماع إلى محطات بث القرآن الكريم مباشرة من المتصفح دون الحاجة لتثبيت أي برنامج.

المشروع مكتوب بالكامل بـ **HTML + CSS + JavaScript** في ملفات مستقلة لا تحتاج إلى سيرفر.

## ✨ المميزات

- 📡 **بث مباشر** لأكثر من 150 إذاعة وقارئ للقرآن الكريم
- 🌙 **وضع الاستماع الهادئ** — خلفية داكنة أنيقة، زخرفة إسلامية خفيفة، إخفاء العناصر الثانوية، وخفض سطوع الشاشة أثناء الاستماع
- 🧠 **حالة البث الذكية** — «جاري الاتصال / يبث الآن / انقطع البث / تعذّر التشغيل» مع إعادة محاولة تلقائية (2ث ← 4ث ← 8ث) وزر **إعادة الاتصال**
- 📺 **بث يوتيوب المباشر** — تحويل روابط القنوات والبث المباشر إلى رابط تشغيل مضمّن صحيح + شاشة احتياطية (إعادة المحاولة / البث عبر يوتيوب / فتح في يوتيوب)
- 📱 **تطبيق ويب (PWA)** — أيقونة على شاشة الهاتف، فتح سريع بواجهة مستقلة، واختصارات مخصصة (المفضلة / الوضع الهادئ / البحث)
- 🔒 **تحكم من شاشة القفل** — اسم الإذاعة وأزرار التشغيل/الإيقاف/التالي/السابق من واجهة النظام (Media Session API)
- 🎨 **أيقونة جديدة** — هوائي سماعات وبرج بث ومصحف مفتوح على رحل، بتذهيب ذهبي على خلفية كحلية متدرجة، بمقاسات 192/512 + Maskable + أيقونة iOS
- 🎭 **أربعة ثيمات ملونة** — زمردي (افتراضي) / فاتح / كحلي / بنفسجي ملكي، تختارها من الإعدادات أو بضغطة زر الثيم (أو مفتاح `T`)، مع نقطة صغيرة على زر الثيم تُظهر لون الثيم الحالي
- 🏷️ **شعار جديد في الترويسة** — محراب + هلال + موجات بث ذهبية داخل بلاطة داكنة بلون الثيم
- 👨‍💻 **توقيع المطور** — «عامر الحلحلي» في نهاية نافذة الإعدادات مع رابط موقعه
- 🕌 **آية اليوم** — آية كريمة تتغير يوميًا أعلى الصفحة
- ✨ **اقتراح ذكي حسب الوقت** — أذكار الصباح صباحًا، المساء مساءً، وسكينة قبل النوم
- 🕐 **آخر استماع** — وصول سريع لآخر المحطات التي استمعت إليها
- ⏱ **مؤقت نوم وجدولة تشغيل** تلقائية
- 🔧 **فحص تلقائي للمحطات** — يكتشف المحطات المعطلة ويخفيها مع إمكانية إعادة فحصها
- 🚀 **أداء محسّن** — تحميل مكتبة HLS عند الحاجة فقط
- 🌐 **يعمل في المتصفح** بدون تثبيت
- 🎨 **واجهة عربية** بتصميم أنيق مع 4 ثيمات ملونة (زمردي / فاتح / كحلي / بنفسجي)
- ⚡ **خفيف وسريع** — HTML + CSS + JS فقط
- 🔊 **تحكم كامل** في التشغيل والإيقاف

## ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `Space` | تشغيل / إيقاف البث |
| `↑` / `↓` | رفع / خفض الصوت (مع عرض النسبة) |
| `→` / `←` | المحطة التالية / السابقة (حسب اتجاه اللغة) |
| `M` | كتم الصوت |
| `F` | إضافة المحطة للمفضلة |
| `S` | تشغيل عشوائي |
| `C` | تبديل وضع الاستماع الهادئ |
| `T` | التنقل بين الثيمات الأربعة |
| `/` | الانتقال إلى حقل البحث |
| `?` | عرض قائمة الاختصارات |
| `Esc` | إغلاق النوافذ / خروج من حقل الكتابة |

> ✅ الاختصارات لا تتدخل أثناء الكتابة داخل حقول الإدخال، ولا تتعارض مع أزرار وحقول التركيز.

## 📲 تثبيت التطبيق (PWA)

1. افتح الموقع في المتصفح (يُفضَّل HTTPS أو `localhost`).
2. **أندرويد / Chrome:** زر التثبيت ✨ في الترويسة، أو القائمة ⋮ ← «تثبيت التطبيق».
   **iPhone / Safari:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. يفتح التطبيق بواجهة مستقلة بأيقونته الخاصة، ويستمر البث في الخلفية مع إظهار
   اسم الإذاعة وأزرار التحكم من شاشة القفل (Media Session).

> ملاحظة: يوتيوب لا يسمح بتشغيل الفيديو في الخلفية داخل المتصفح، لكن البث الصوتي
> يستمر بشكل طبيعي حتى مع إغلاق الشاشة.

### إعادة توليد الأيقونات

ملفات PNG مشتقة من ملفّي `icon.svg` و`icon-maskable.svg` وتُولَّد من جديد بمتصفح Chrome/Edge (بلا رأس) للحصول على تطابق دقيق مع الفلاتر والنصوص:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/render-icons.ps1 -OutDir .
```

> يتطلب وجود **Chrome** أو **Edge**. يمكن تمرير المسار يدويًا عبر `-Browser "C:\path\to\chrome.exe"`.
> تُرسم الأيقونة الأساسية بدقة 512 ثم تُصغَّر المقاسات الأصغر بإعادة أخذ عينات عالية الجودة؛ ونسخة الـ Maskable بخلفية كاملة الحواف ومحتوى داخل منطقة الأمان.
